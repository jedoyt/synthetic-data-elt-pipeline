# Location Metadata
```
location_id
Type: INTEGER, int
Description: ID number for location
```
```
city
Type: TEXT, str
Description: Name of city
```
```
country
Type: TEXT, str
Description: Name of country
```
```
latitude
Type: FLOAT, float
Description: a coordinate whose grid (and exact points) runs side-to-side (east to west) around the earth
```
```
longitude
Type: FLOAT, float
Description: a coordinate whose grid (and exact points) runs up-and-down (norht and south) from pole to pole
```

## JSONL Example
```json
{
    "location_id": 27, 
    "city": "Tallahassee", 
    "country": "United States", 
    "latitude": 30.4124334, 
    "longitude": -84.2831162
}
```
