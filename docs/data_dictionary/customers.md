# Customer Metadata
```
customer_id
Type: INTEGER, int
Description: Unique customer identifier
```
```
registration_ts
Type: TIMESTAMP, datetime
Description: The timestamp (ISO-format) when the customer registered as an app user
```
```
username
Type: TEXT, str
Description: Unique identifier name for each customer
```
```
email
Type: TEXT, str
Description: Customer's email address that should also be unique for each customer
```
```
gender
Type: TEXT, str
Description: The customer's gender (Includes more genders other than Male or Female)
Description
```
```
age
Type: INTEGER, int
Description: Customer's age
```
```
nationality
Type: TEXT, str
Description: Customer's country of nationality
```
