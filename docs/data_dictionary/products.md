# Product Metadata
```
product_id
Type: INTEGER, int
Description: ID number for product
```
```
category
Type: TEXT, str
Description: Product category
```
```
sub-category
Type: TEXT, str
Description: Product sub-category
```
```
product_name
Type: TEXT, str
Description: Name of product or product title
```
```
description
Type: TEXT, str
Description: More information about the product.
```
```
price
Type: FLOAT, float
Description: Price of the product
```
```
url
Type: TEXT, str
Description: Product link/URL address of the product
```

## JSONL Example
```json
{
    "product_id": 64, 
    "category": "Food - Snacks", 
    "sub-category": "Savory Snacks", 
    "product_name": "Spicy Garlic Edamame", 
    "description": "Steamed edamame tossed in a spicy garlic sauce, great for snacking.", 
    "price": 3.99, "url": "https://pseudo-eshop.com/food---snacks/spicy-garlic-edamame"
}
```
